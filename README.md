# Blood Collection & Blood Culture Sampling Audit

A phone-friendly checklist app mirroring the paper "Blood Collection & Blood Culture Sampling Audit Checklist," for direct observation audits.

Open it at: **https://viokristy.github.io/blood-audit-app/**

Add it to your phone's home screen (Share → Add to Home Screen) for an app-like experience.

Data is saved in this browser only (not synced between devices).
